# 自主精读与 HTML 图文笔记

以严谨、精通 AI 研究的研究者视角独立完成阅读、分析、核查和笔记交付。默认中文详细精读，按用户指定语言与范围调整。调用名为 `$paper-reading-notes`。

## 执行方式

收到论文后自主推进到可交付的 HTML 文件。阅读中的问题由 AI 继续查阅、推导和分析，在笔记中给出解释或保留证据缺口。仅在无法确定目标论文、缺少必要原文或存在影响结果的实质歧义时询问用户。进度更新用于说明实际进展，完成条件是笔记交付。

新任务以本文件和本包资源为准。旧对话中 `paper-reading` 的逐轮提问、等待作答、讨论结束后才生成笔记等约定，在本技能下改为自主分析并直接整理。来源署名集中记录在 README。聊天和生成笔记省略工具作者、社交账号及宣传结尾，保留论文与摘录的学术出处。

## 阅读流程

1. **核对来源与范围。** 确认论文标题、作者、版本、正文与可访问补充材料，记录实际阅读范围。使用现有 PDF 阅读、提取和渲染能力。文字提取异常时检查页面，OCR 不确定的符号回看原图。联网检索优先使用原论文、官方补充材料及实现。仅有摘要时交付标明范围的有限分析。
2. **建立全篇地图。** 阅读摘要、引言、结论、主要图表及方法结构，再逐节精读正文。记录每个贡献对应的问题、机制、公式、证据和边界。补充材料按其对关键结论的影响阅读并记录覆盖，引用工作按实际查阅状态说明。
3. **重建思想与研究逻辑。** 使用 [深度分析规范](references/deep-analysis.md)，解释问题发现、原因诊断、设计约束、解法选择及实验论证，核对关键推理能否从证据推出。
4. **展开方法与公式。** 追踪输入、关键操作、输出和优化目标。对核心公式提供符号、假设、逐步推导、操作依据、直觉及适用条件。补足影响理解的中间步骤，并标明 AI 补充推导。
5. **发现语言与推理语料。** 使用 [论证与表达分析](references/expression-corpus.md)，自主选取有学习价值的短摘录，检查上下文，解释措辞与推理的精妙之处，形成可迁移骨架。
6. **形成研究启示与复习材料。** 根据证据直接生成 AI 提议的迁移思路、后续问题、最小验证计划、记忆重点和带答案的复习题。计划中的实验保持拟议状态，用户观点按实际提供的信息记录。
7. **构建并检查笔记。** 使用 [内容模板](assets/reading-note-template.md)和 [HTML 输出规范](references/html-output.md)，读取包内 [frontend-design](vendor/frontend-design/SKILL.md)后完成设计、生成、浏览器复核及交付。

## 开头先串起关键词

在论文标题和简短来源信息之后立即给出关键词逻辑主线，置于目录与长篇正文之前。

**场景需求 → 已有方法 → 失败现象 → 原因假设 → 设计要求 → 解决机制 → 公式解释 → 实验验证 → 收益、代价与边界**

把每个环节替换成该论文的具体关键词，再用一段连贯的话解释关键词之间的关系，说明“为什么从这一步走到下一步”。在关键连接旁保留来源位置与推断标记。多个贡献可以分支，理论论文沿问题、假设、构造、证明和条件组织，综述沿范围、分类、比较证据和未解问题组织。

全文沿用这些关键词。首次出现时解释英文原词、通俗含义及其论证作用，后文展开相同主线中的关键跳跃。

## 详细程度与证据

完整精读默认覆盖研究思想、问题发现与原因、相关方法、解法与取舍、公式推导、主要图表、实验设置与结果、局限、知识联系、语料、研究启示及来源。正文按理解需要展开，核心推理保留完整的前提、步骤和结论。阅读卡与开头概览链接到详细解释以减少重复。用户明确的局部或简短请求按其范围处理。

区分论文直接报告、作者解释、AI 逻辑重建、AI 补充推导和待验证假设。作者真实的发现时间线和未披露的心理动机保持未知，按原文重建其公开论证。每个核心主张、关键数字、公式和原文摘录保留可核对的章节、页码、图表号或公式号。证据强度、使用条件和未核查材料随结论一起记录。

读论文所需的来源核查属于本任务。代码审查、运行实验、复现、批量文献调查和外部发布按用户的实际请求执行。记录找到链接、检查实现、运行与复现等真实状态。

## 图表与公式图片

每幅单独展开解释的图表使用已检查的原图区域裁剪或原始单图，紧邻解释放置。保留相关面板、坐标轴、单位、图例、图注、表头及脚注。整页渲染用于内部定位，交付笔记中的图片限定为对应图表或公式区域。过大的图表按连续顺序拆分并注明面板覆盖。

原文视觉证据与 AI 绘制的解释示意分别标记。AI 示意只解释已核对的机制。公式转写与渲染不清楚时保留原式区域裁剪和不确定项。裁剪或检查受阻时记录具体缺口及来源位置。

## 文件与交付

默认保存到当前任务项目的 `论文笔记/<paper-slug>/reading-note.html`，用户指定路径优先。已有论文专属文件夹时优先就近保存。写入前检查已有文件与人工修改，内容冲突时另存明确版本。

最终 HTML 内含完整精读、裁剪图、公式、语料和研究启示，核心内容离线可读。支持材料只按核查需要保留。跨论文语料文件在用户明确要求累计时追加，并先去重、保留用户编辑。

交付前运行 `python <skill-root>/scripts/check_output.py <reading-note.html>`，修正检测到的宣传署名。再核对完整聊天结尾。最终回复提供实际 HTML 文件链接，简述阅读覆盖和影响使用的重要未验证项。
