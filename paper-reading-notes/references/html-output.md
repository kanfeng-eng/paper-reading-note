# HTML 图文笔记规范

## 设计与文件

先读取 [frontend-design](../vendor/frontend-design/SKILL.md)，据论文主题和长期阅读需求形成简短的配色、字体、宽度、导航及关键词主线设计，然后构建最终页面。包内资源相对技能目录解析，可独立使用。

生成 UTF-8、带正确语言与 viewport 的完整 HTML。默认保存于论文任务项目，已有论文专属目录时就近保存。人工修改过的文件先核对，冲突时另存版本。正文按理解需要详细展开，页首的概览用于进入长篇分析。

在标题和简短来源之后，先展示具体关键词串成的逻辑主线和连贯解释，再展示章节导航。主要章节具有可链接的标题。阅读卡、重点记忆和复习题为正文提供查阅入口。

## 内容与呈现

- 正文涵盖研究思想、发现线索、成因分析、解法依据、方法细节、公式推导、实验与证据、局限、语料及研究启示。按论文类型调整适用章节。
- 使用清晰的字重、字号与间距区分标题、正文、图注、原文引用和 AI 解释。颜色辅助已有的文字标记。优先使用本地字体，中文设置可靠回退。
- 图表紧邻对应讲解，使用已检查的图表区域裁剪或原始单图，保留相关面板、坐标轴、单位、图例、图注和表格脚注。图注给出图表号、PDF 页或印刷页标识、覆盖范围和来源。
- 整页渲染保存在内部定位材料中。最终嵌入图片限定为实际图表、公式或必要的局部证据。AI 绘制的机制示意单独标明。
- 公式用离线可用的数学方式呈现，复杂公式可使用原式区域裁剪。公式原式、符号说明、中间推导及操作依据在内容层次上清楚对应。检查上下标、希腊字母、分数、求和范围和溢出。
- 语料以有上下文的段落排版，原文、释义、关键词分析、迁移骨架和使用条件易于区分，保留可定位出处。
- 重要结论、条件、局限和 AI 推断直接可见。复习答案可使用原生 `details/summary` 单独展开，并附来源。

## 离线与可访问性

CSS、必要脚本、展示图片和必要的数学资源内嵌。图像使用 data URL，外部论文链接仅作来源。正文、图片和公式的阅读具备离线可用性。对论文文字进行正确转义，核对链接与锚点。

桌面与窄屏均可读。正文正常换行，长表格、公式和代码局部滚动。图片适应内容宽度，必要时提供可用的放大操作。目录、链接和控件可通过键盘使用，焦点清晰。尊重减少动画设置。打印样式保持正文、图表和来源可读，并展开参考答案。

搜索、筛选、复制等控件只在有实际阅读用途时提供，加入后逐项检查。核心阅读内容通过正常文档结构访问。

## 检查与交付

完成后实际打开最终 HTML，检查桌面与窄屏的正文、导航、图表、公式、语料及复习交互。核对图片的裁剪边界和面板覆盖，查看截图以发现遮挡与溢出。核对离线资源、键盘操作、打印样式和必要的数学渲染。

将关键数字、符号、推导条件、比较设置、原文摘录和来源逐项回查。逐节核对阅读卡与正文覆盖是否一致。摘要、正文、补充材料、引用文献、代码或实验状态按实际完成情况记录。未验证事项写明其对结论的影响。

交付前运行以下检查，检测到宣传署名时修正后重跑。此脚本只检查已知署名形式，论文事实、推理、引用和页面质量仍须按上述步骤核查。

```text
python <skill-root>/scripts/check_output.py <reading-note.html>
```

最终聊天提供实际保存的 HTML 链接，简述精读范围和重要缺口。笔记和聊天中的工具作者、社交账号及宣传结尾按入口规则处理，学术引用附在相应结论、图表及摘录旁。
